# Making Sense of Complex Problems

An independent editorial journal hosted on GitHub Pages.

- `index.html`: homepage
- `styles.css`: editorial visual system
- `articles/when-measuring-success-causes-failure.html`: first investigation
- `notebook/the-shipping-container.html`: early research brief

GitHub Pages should use branch `main` and folder `/(root)`. Notebook entries are research directions, not finished articles. No publication dates are fabricated.
