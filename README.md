# Harika — PM Portfolio starter

This is a static HTML/CSS/JS portfolio starter designed for GitHub Pages.

## Files
- `index.html` — homepage
- `styles.css` — responsive editorial styling
- `script.js` — small interaction enhancement
- `projects/strava.html` — first case-study page

## Before publishing
1. Replace `Harika` with your preferred public display name if needed.
2. Replace the LinkedIn, GitHub and email placeholder URLs in `index.html`.
3. Add your resume PDF to the repository and link it from the homepage when ready.
4. Review every project statement for accuracy and confidentiality.

## Publish with GitHub Pages
1. Create a new GitHub repository. For a personal site, the repository can be named `YOUR-USERNAME.github.io`.
2. Upload the contents of this folder to the repository root (not the enclosing folder).
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then Save.
6. Wait for the Pages URL to appear in the Pages settings.

If you use a repository with another name, the URL will generally be `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`.

## Notes
The website uses Google Fonts from a CDN. If you prefer no external font requests, remove the font links and use the fallback fonts in `styles.css`.
